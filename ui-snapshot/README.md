# 观茶当前 UI 快照

这是从当前项目复制出的独立 UI 文件夹，来源版本为 `cb28f9c`（2026-08-26）。

包含：

- `index.html`：页面入口
- `styles.css`：当前页面样式
- `app.js`：页面交互与状态逻辑
- `frontend/`：页面依赖的前端运行模块
- `assets/`：页面插图、图标和风味资源

## 本地查看

在本文件夹内启动静态服务器：

```powershell
python -m http.server 8080
```

然后打开 `http://127.0.0.1:8080/`。这份快照用于查看当前 UI；如果不启动项目后端，上传分析等需要后端的功能不会执行。
